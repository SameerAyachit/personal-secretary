# ADR-004: NVIDIA NIM replaces Groq as the default LLM provider

Date / Status: 2026-11-15 / accepted (explicit user decision)

Context: The plan (§6, §7) names Groq as the primary provider. The user no longer has a working Groq key and holds an NVIDIA API key (build.nvidia.com), which serves Nemotron 3 Ultra and Nemotron 3.5 Super VL through an OpenAI-compatible endpoint. AGENTS.md says the plan wins when code and plan disagree, so this records the deviation.

Decision: The default and only shipped provider (besides the unconfigured Gemini placeholder) is `nvidia`: base URL `https://integrate.api.nvidia.com/v1`, default model `nvidia/nemotron-3.5-super-vl-120b-a12b`, key in Credential Manager as `llm_api_key:nvidia`. Groq defaults, limits and key checks are removed. Nemotron models think by default, so the client sends `chat_template_kwargs: {"enable_thinking": <llm.thinking>}` (default false) for `nemotron` model ids only, via a generic `extra_body`. An inline `<think>...</think>` trace is stripped from replies. The local limiter defaults to the published trial ceiling (40 requests/min, 10,000/day).

Rationale: No new dependency and no new client class: `OpenAICompatClient` already speaks the protocol. Thinking off keeps replies fast and tool calls reliable; users can turn it on in `config.toml`. The model list in Settings comes from `/models`, which also confirms the exact ids available to the key (model ids on the trial endpoint change; one Nemotron 3 Super id was removed on 2026-10-20).

Consequences: (1) NVIDIA's trial terms say inputs and outputs are recorded and may be used to improve their products. The app sends chat, task, calendar and Gmail-triage text to the model, so do not use the trial endpoint for content that must stay private. (2) Function calling is listed as supported for Super VL but must be checked live for each model. (3) To go back to Groq or use another OpenAI-compatible provider, add a provider entry under `[llm.providers]` in `config.toml`, set `llm.active`, and store its key as `llm_api_key:<name>`. No code change is needed. (4) The master plan still mentions Groq; it was intentionally not rewritten.
