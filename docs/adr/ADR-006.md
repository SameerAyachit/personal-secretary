# ADR-006: Quiet hours are not built (for now)

Date / Status: 2026-11-15 / accepted

Context: Plan §10.5 describes optional quiet hours (for example 23:00-07:00): non-priority reminders that would fire inside the window land in the inbox silently, with priority reminders ignoring the window and the default being off. The config keys `app.quiet_hours_*` existed but nothing ever read them, so they were removed earlier (see CHANGELOG, "Removed").

Decision: Do not implement quiet hours in v1. The plan marks the feature optional and default-off, so it adds no value until someone turns it on, while it touches the most safety-critical path in the app (the reminder tick and the toast/popup layers) and needs its own tests for midnight wrap-around, time-zone changes and wake-from-sleep catch-up.

What already covers the need: Windows Focus Assist / Do Not Disturb silences toasts, and the Inbox remains the source of truth (plan D10), so nothing is lost while the user is away or has notifications off. The "While you were away" summary groups what fired while the app was closed.

Consequences: A reminder always notifies at its time. To revisit, add `app.quiet_hours_start/end` config, apply the window in `scheduler/ticker.py` only to the toast/popup step (never to the inbox write), exempt `priority=1`, and add the tests listed above.
